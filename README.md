# Infinitum — мод в стиле Avaritia (Forge 1.20.1)

## Как получить .jar

**Вариант 1 — на своём компьютере**
1. Установи JDK 17 (например, Temurin 17 с adoptium.net).
2. Открой папку мода в терминале и запусти:
   - Windows: `gradlew.bat build`
   - Linux/macOS: `./gradlew build`
3. Первая сборка скачивает Minecraft и Forge (5–15 минут).
4. Готовый мод: `build/libs/infinitum-1.20.1-1.0.0.jar` → положи в папку `mods` (нужен Forge 1.20.1, версия 47.x).

Проверить в игре без установки: `gradlew runClient`.

**Вариант 2 — без Java, через GitHub**
Залей папку в новый репозиторий GitHub → вкладка **Actions** → сборка запустится сама →
скачай архив `infinitum-mod` с готовым .jar.

**Анимации:** переливающиеся радугой инструменты и броня, вращающиеся сингулярности,
часы с идущими стрелками, пульсирующие верхушки машин, вращающийся компрессор, мерцающий кристалл дюпа,
горящий Меч Черепов; частицы у предметов в руке, вокруг брони и над блоками.

Все инструменты и броня не ломаются. Рецепты удобно смотреть через JEI (в нём видны только обычные рецепты).

**Кристалл дюпа (поблажка)**
Рецепт (обычный верстак):
```
Алмаз   Изумруд   Алмаз
Изумруд Око Эндера Изумруд
Алмаз   Изумруд   Алмаз
```
- **ПКМ** с кристаллом в основной руке — копирует весь стак из второй руки (с зачарованиями).
- **В верстаке:** кристалл + любой стак → получаешь копию стака, а кристалл и оригинал остаются.
  Shift+клик по результату — копирует, пока не заполнится инвентарь.

**Реалистичные блоки (27)**
Мрамор, известняк, сланец, травертин, гнейс (генерируются под землёй жилами),
их полированные/кирпичные/плиточные варианты (крафт 2x2 или камнерез), асфальт, железобетон,
ржавый железный блок, сжатый булыжник (x1/x2/x3), сжатые земля/песок/гравий/незерак,
блоки кристальной матрицы, нейтрония и анимированный блок Бесконечности.

## Рецепты экстремального верстака
Лежат в `src/main/resources/data/infinitum/recipes/extreme/` — простые JSON,
легко поменять (пробел = пустая клетка).
